# Public Assets Directory (`public/`)

> **EMG Core v49 Execution:** Optimized for rapid comprehension, clean asset governance, and high-performance frontend delivery.

## Executive Summary
The `public/` directory stores raw, unprocessed static assets (images, fonts, media) served directly to the client. This document outlines structural organization, strict naming conventions, and correct root-relative referencing methods to maintain optimal application performance.

## Usage Guidelines

| Category | Best Practice | Example |
| :--- | :--- | :--- |
| **Organization** | Group files into descriptive subdirectories as the project scales. | `images/`, `icons/`, `fonts/` |
| **Naming** | Use lowercase, kebab-case identifiers with explicit semantics. | `company-logo.svg`, `hero-background.webp` |
| **Performance** | Compress and properly size all assets prior to repository commitment. | Fast client-side loading times |

## Referencing Public Assets

Reference assets stored in the `public/` directory directly from the root URL (`/`) within your components and templates:

```html
<!-- Example: Referencing an optimized image from the public directory -->
<img 
  src="/images/company-logo.svg" 
  alt="Company Logo" 
  width="150" 
  height="40" 
  loading="lazy" 
/>
```
